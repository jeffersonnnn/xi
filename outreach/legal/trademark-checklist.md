# USPTO Trademark Filing Checklist

## Overview

File for "$XI" and/or "The People's XI" via TEAS-Plus (cheapest option at $250/class).

**File at**: https://www.uspto.gov/trademarks/apply

---

## Step-by-Step

### 1. Prepare Before Filing

- [ ] Decide on mark format:
  - **Standard character mark**: "$XI" (protects the text in any font/style)
  - **Special form mark**: "$XI" with specific logo/design (protects that specific design)
  - **Recommendation**: File standard character first — broader protection, cheaper
- [ ] Search the USPTO database (TESS) to confirm no conflicting marks: https://tess2.uspto.gov
- [ ] Search for "XI" in Class 9 and Class 41 specifically

### 2. Choose Classes

| Class | Description | Covers | Cost |
|-------|-------------|--------|------|
| **Class 9** | Downloadable software | Mobile app, web platform | $250 |
| **Class 41** | Entertainment services | Voting platform, sports entertainment | $250 |
| **Class 42** | SaaS / technology services | Web-based voting platform | $250 |

**Recommendation**: Start with Class 9 + Class 41 = $500 total. Add Class 42 later if needed.

### 3. Prepare Your Description of Goods/Services

**Class 9**:
"Downloadable mobile application for fan voting and sports entertainment; downloadable software for token-weighted governance and voting"

**Class 41**:
"Entertainment services, namely, providing an online interactive platform for fan voting on sports team selections; providing a website featuring information about World Cup football"

### 4. Filing Basis

Choose one:
- **1(a) — Use in commerce**: If the product is already live and you have evidence of use
- **1(b) — Intent to use**: If the product isn't live yet (additional $100 fee later when you show use)

**You should file under 1(a)** since the app is live. You'll need a "specimen" — a screenshot of the live site showing the mark in use.

### 5. Specimens to Prepare

- Screenshot of the $XI logo on the live website header
- Screenshot of the App Store / Google Play listing (once submitted)
- Screenshot of the voting interface showing "$XI" branding

### 6. Applicant Information

- **Individual or entity**: File under your personal name OR your business entity (if C-Corp is formed, file under the corp)
- **Address**: Your business address
- **Email**: Your official email

### 7. File

- Go to https://www.uspto.gov/trademarks/apply
- Select "TEAS Plus" filing option
- Fill in all fields per the above
- Pay $250 per class
- **Save your serial number** — this is your tweetable artifact

### 8. After Filing

- You'll receive a serial number immediately
- An examining attorney reviews in ~3-4 months
- If approved, the mark publishes for 30-day opposition period
- If no opposition, registration issues ~2 months later
- Total timeline: ~8-12 months from filing to registration

### 9. The Tweet

> $XI has filed for trademark protection with the USPTO.
> Serial No: [YOUR_SERIAL_NUMBER]
> The People's Starting XI isn't just a meme — it's a brand.
