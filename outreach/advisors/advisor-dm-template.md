## Tips for Outreach

1. **Personalize**: Reference something specific they've done
2. **Keep it short**: DMs should be under 100 words
3. **Lead with the product**: Link to the live site, not a pitch deck
4. **Be upfront about the ask**: "advisor" + "small token allocation" + "no heavy time commitment"
5. **Follow up once**: If no response in 3-4 days, one follow-up. Then move on.
6. **Target 5-10 people**: You only need 1 yes.
